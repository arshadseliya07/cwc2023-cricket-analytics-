# 🏏 CWC 2023 Cricket Analytics — Power BI Dashboard

A complete Power BI analytics project analyzing the 
Cricket World Cup 2023 across 48 matches, 10 teams 
and 11 stadiums across India.

## Dashboard Pages
1. KPI Overview — Team Dominance, Batting Strength, 
   Match Analysis
2. Team Dominance — Win %, margins, overs played
3. Batting Strength — Scores, run rate, strike rate, 
   boundaries
4. Losing Team Weakness — Extras, wickets lost, 
   win % analysis
5. Match Analysis — Toss impact, bat first vs chase, 
   day vs day-night
6. Stadium Wise Analysis — Venue conditions, 
   scoring patterns

## Key Findings
- India won 90.91% of matches — most dominant team
- Toss winners won only 39.6% of matches
- South Africa scored highest team total — 428 runs
- England loses most wickets on average (9.8 per match)
- Arun Jaitley Stadium most batting friendly venue
- Pakistan and Afghanistan prefer chasing (60% win rate)

## Tools Used
- Power BI — Interactive dashboards, KPI cards, 
  slicers, DAX measures

## Dataset
CWC 2023 match data — 48 matches across 10 teams
